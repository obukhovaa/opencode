### Review follow-ups

- [x] `internal/langfuse/prompts.go`: escape the prompt name with `url.PathEscape`, not `url.QueryEscape` — the latter encodes a space as `+`, which is a literal plus in a path, so a prompt named `team review` was requested as `team+review` and 404'd.
- [x] `internal/langfuse/prompts.go`: remember a failed fetch for a retry floor (`promptEntry.lastAttempt` / `lastErr`). A failed re-fetch cannot advance `fetchedAt`, so the entry stayed stale for the whole outage and every caller re-attempted — serialised under the entry lock, i.e. N × the fetch timeout. Measured 20 callers → 20 requests before, 1 after.
- [x] `internal/langfuse/prompts.go`: re-check `ctx.Err()` after taking the entry lock, so a cancelled caller is not handed a stale copy with a nil error.
- [x] `internal/langfuse/prompts.go`: distinguish an unsupported chat shape (blocks carrying neither role nor text — a `placeholder`, or array-valued `content`) from a genuinely empty prompt; warn with blocks-seen vs blocks-kept when flattening drops any; treat an absent `prompt` field as empty rather than as an unknown type.
- [x] `cmd/acp.go`: call `initLangfusePrompts`. It was the third entry point and had none, so a referencing agent could not be constructed there — `InitPrimaryAgents` logged and continued, making the agent silently absent (or failing boot if it was the only primary).
- [x] `cmd/langfuse_prompts.go`: run the warm-up fetch in the background. It was synchronous inside the TUI's startup spinner, so an unreachable Langfuse was a 30s boot hang; nothing downstream waits on it, and a use-time fetch that races it collapses onto the same single flight.
- [x] `internal/llm/agent`: extract `resolveManagedPrompt` / `resolveRegisteredPrompt` and use them for the `summarizer` and `descriptor` providers (built by name, not through the factory) — a `langfusePromptPath` on either was silently ignored while an inline `prompt` on the same agent worked.
- [x] `internal/llm/agent/agent.go`: keep the resolved prompt on the agent (`basePrompt`) and re-supply it from `Update`, so an in-process model switch does not swap a managed system prompt for the built-in one.
- [x] `internal/flow/include.go`: a step's declared prompt source suppresses inheritance of the competing source (`suppressedByOwnPromptSource`), so overriding a template's `prompt` with `langfusePromptPath` no longer collides and overriding a path with an inline prompt no longer strands the template's label. `langfusePromptLabel` stays independently inheritable for label-only overrides.
- [x] `internal/flow/registry.go`: point the "declares both" error at the `extends` list — the step's own YAML may show only one key.
- [x] `internal/flow/service.go`: skip prompt resolution for a step that is about to be postponed (it returns before the prompt is used, and an unreachable Langfuse turned a park into a step failure); trim the path so the runtime agrees with validation; log the resolved version.
- [x] `internal/agent/registry.go`: `normalisePromptSources` on the merged entry — trim the path, and drop a label with no path with a warning. `ValidateAgentPromptSource` no longer rejects a label without a path per layer, so a higher layer can re-label a lower layer's path instead of failing the boot with a message contradicting what the user wrote. `applyConfigOverrides` / `mergeMarkdownIntoExisting` apply a label-only override.
- [x] `internal/agent/registry.go`: log a markdown agent's parse failure at Error, not Warn — the whole definition is discarded, which is the quiet half of an asymmetry whose JSON equivalent fails the boot.
- [x] Docs: correct `opencode.json` → `.opencode.json` in `docs/flows.md`; add the freshness table (primary agents are pinned until restart, contradicting the earlier blanket TTL claim) to `docs/telemetry.md`; note that `` !`shell` `` in a managed prompt executes outside the permission system, so Langfuse prompt-write access implies shell access; document that `fallback.retry` does not cover a resolve failure; give the README's `agents` example a `model` (the JSON schema requires one).
